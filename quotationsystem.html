5. QUOTATION SYSTEM

Rows of Section = Numbers

Example: (AB/;01-12;)

The 2 letters represent the section
Example: (AB/

The ";" represent that you must start reading after the nearest "."
Example: (AB/;
Example: (AB/;.01-12;), (AB/;..01-12;), (AB/;...01-12;), (AB/;01-12;.), (AB/;01-12;..), (AB/01-12;...)

The two numbers represent which row you start reading on and which one you stop reading on, if the text consists of one row you only write that number.
Example: /;01-12;), /;01;)

If you want a text read from beginning until the ending you manually use B and E to replace the two numbers.
Example: /;B-E;)
